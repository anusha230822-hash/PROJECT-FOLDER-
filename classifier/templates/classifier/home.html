How the System Works

The complete end-to-end data processing and semantic classification pipeline

1. Upload
Satellite image ingested via web interface
2. Preprocess
Resizing (128x128), RGB, denoising & norm
3. Features
Color (RGB/HSV), texture & Canny edges
4. Random Forest
Ensemble trees predict land-cover class
5. Ontology
Mapped to Protégé OWL taxonomy
6. Knowledge Base
Stored with confidence & visual analytics

Supported Land-Cover Classes

Forest

Dense tree canopy, natural woodlands, and evergreen forests.

Water

Lakes, rivers, reservoirs, and natural open aquatic bodies.

Agriculture

Arable farmlands, cultivated croplands, and geometric harvest plots.

Urban

Residential structures, high-density settlements, roads & buildings.

Barren Land

Bare soil, rock surfaces, quarries, and non-vegetated dry terrain.

Why Use an Ontology with Machine Learning?

Standard ML algorithms only output isolated numbers or string labels (e.g. Forest). By integrating an OWL/RDF Semantic Web Ontology:

  • The system understands that Forest is a type of Vegetation, which is a type of LandCover.
  • Automated spatial reasoning connects related concepts (e.g., rivers and lakes belong to WaterBody).
  • The application knowledge-base can be queried semantically using standard ontology traversal and SPARQL principles.
Diploma Project Architecture

Designed for clarity, modularity, and high-scoring viva presentations:

  • Image Processing: Deterministic 15-feature extraction using OpenCV and Pillow.
  • Classifier: Scikit-Learn Random Forest ensemble with full probability distribution.
  • Ontology Engine: Owlready2 parsing W3C standard Protégé-compatible OWL file.
  • Backend & Storage: Django web framework with relational SQLite database.
