Ontology in Viva & Research

An ontology formally represents knowledge within a specific domain as a hierarchy of concepts and the relationships between them.

The OWL (Web Ontology Language) file encodes domain knowledge in RDF/XML syntax. It enables interoperability with semantic reasoning software such as Protégé and graph triple-stores.

We utilize Owlready2, a Python library that translates OWL ontologies directly into Python objects. Upon ML prediction, our ontology_mapping.py traverses parent classes up to the root concept.

Primary relationship is isA (rdfs:subClassOf). For example, Forest → isA → Vegetation → isA → LandCover.
